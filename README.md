# 30-Day Oracle SQL Learning Journey

An intensive, 30-day developer log detailing my journey learning Oracle SQL from scratch, progressing from relational concepts to advanced performance tuning and PL/SQL.

## Project Phases
1. **Employee Management Database (Days 1-8)**: Explored basic schema constraints, sorting, aggregations, functions, and regular expression validation.
2. **E-Commerce Analytics Database (Days 9-17)**: Deep dive into joins, set operators, analytic rankings, subqueries, hierarchy, and database synchronization via MERGE.
3. **Performance & PL/SQL (Days 18-25)**: Indexing, query plans, stored procedures, exceptions, and packages.
4. **Banking Transaction System Capstone (Days 26-30)**: Triggers, security policies, complex lock contention mitigation, production-grade bulk operations, and pipelined analytics.
