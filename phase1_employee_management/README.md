# Phase 1 - Employee Management Database

Completed core lessons regarding fundamentals of Oracle SQL.

### Core Concepts Implemented:
1. **DDL & DML**: Initialized database objects (`CREATE TABLE`) and loaded mock data.
2. **Constraints**: Protected schemas with unique, check, primary, and foreign key boundaries.
3. **Built-in Functions**: Utilized string transformations (`SUBSTR`, `INSTR`) and date arithmetic (`MONTHS_BETWEEN`).
4. **Aggregations & Grouping**: Evaluated payroll metrics, resolving `GROUP BY` structures and `HAVING` groups.
